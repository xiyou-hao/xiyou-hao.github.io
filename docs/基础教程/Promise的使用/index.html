Promise的使用

1.什么是Promise?​

1.抽象表达
	-Promise是一门新的技术(ES6规范)
	-Promise是js中进行异步编程的新解决方案(旧方案是使用回调函数)
    	例如:定时器/Ajax/点击事件/xhr
2.具体表达
	-从语法上来说:Promise是一个构造函数
		例如:let promise = new Promise((resolve,reject)=>{})
	-从功能上来说:Promise对象用来封装一个异步操作并可以获取其成功/失败的结果值
3.实际表达
	-Promise就是一个用来存储数据的容器,可以存储异步调用的结果,通过resolve,reject两个函数存储,这两个函数是Promise内部定义的

2.为什么要用Promise?​

1.指定回调函数的方式更加灵活
	-旧的:必须在启动异步任务前指定
	-Promise:启动异步任务=>返回promie对象=>给promise对象绑定回调函数（甚至可以在异步任务结束后指定/多个)
2.支持链式调用,可以解决回调地狱问题
	-回调地狱:回调函数嵌套调用，外部回调函数异步执行的结果是嵌套的回调执行的条件
	-回调地狱的缺点?
		不便于阋读
		不便于异常处理

3.工作流程​

						  fulfilled状态		.then()
						成功,执行resolve()	-->回调onResolved()				
new Promise() -->执行异步操作										-->新的Promise对象
						失败,执行reject()	-->回调onRejected()
						  rejected状态		.then()/.catch()

4.Promise初体验​

// 获取随机数
function getRandomInt (min, max) {
    return Math.floor(Math.random() * (max - min + 1)) + min;
}

// resolve  函数类型参数,存成功的值
// reject   函数类型参数,存失败的值
const p = new Promise((resolve,reject)=>{
    setTimeout(()=>{        // Promise包裹异步任务
        let num = getRandomInt(1,100)
        if(num <= 30){
            resolve(num)  // 存成功的值,PromiseState状态改为fulfilled
        }else{
            reject(num)   // 存失败的值,PromiseState状态改为rejected
        }
    },1000)
})

// then接收两个函数形式的参数,成功就执行第一个,失败就执行第二个
p.then((value)=>{  // 成功的值作为参数传入
    console.log("获取法拉利"+ value +"辆");
},(reason)=>{      // 失败的值作为参数传入
    console.log("什么都没有得到"+reason);
})

5.Promise状态的改变​

1.Promise的状态与值​
只有两种,并且一个Promise的状态只能改变一次,无论成功与否,都会有一个结果值,成功的数据一般称为value,失败的数据一般称为reason
[[Prototype]]: Promise
[[PromiseState]]:状态值 "pending"   fulfilled"  "rejected"
[[PromiseResult]]:成功/失败的值 value

1.pending  ---> fulfilled
2.pending  ---> rejected

6.Promise实例的方法​

Promise 构造函数：Promise (excutor){}
(1) executor 函数：执行器 (resolve, reject) =>{}
(2) resolve 两数：内部定义成功时我们调用的函数 value =>{}
(3) reject 所数：内部定义失败时我们调用的函数 reason =>{}
说明：executor 公在 Promise 内部立即同步调用，异步操作在执行器中执行
说明：指定用于得到成功value 的成功回调和用于得到失败 reason的失败回调
返回一个新的promise 对象
1.then()​
Promise.prototype.then 方法：(onResolved, onRejected)=>{}
	(1) onResolved 两数：成功的回调函数 (value) =>{}
	(2) onRejected 函数：失败的回调函数 (reason)=>{}
then需要两个回调函数作为参数,回调函数用来获取Promise中的数据	
通过resolve存储的数据,会调用第一个函数返回
通过reject存储的数据或者出现异常时,会调用第二个函数返回

promise.then((value)=> {							
    console.log("正常输出",value);
},(reason)=> {
	console.log("异常输出",reason);
})
2.catch()​
Promise.prototype.catch 方法：(onRejected)=>{}
	(1) onRejected 所数：失败的回调函数(reason)=>{}

catch只需要一个回调函数作为参数,用来读取reject存储的数据或者出错试的数据
promise.catch((reason)=> {
	console.log("异常输出",reason);
})
3.finally()​
-无论是正常存储数据还是出现异常了,finally总会执行
-但是finally的回调函数中不会接收到数据
-finally()通常用来编写一些无论成功与否都要执行的代码

promise.finally (()=> {
	console.log("成功与否都会输出这句话");
})

7.Promise对象的方法​

1.resolve()​
Promise.resolve()方法：(value)=>{}
	(1) value: 成功的数据或者Promise对象
	说明: 返回一个成功/失败的promise 对象

// 如果传入的参数为非Promise类型的对象,则返回的结果是成功状态的Promise对象
const p1 = Promise.resolve(666)

// 如果传入的参数为Promise类型的对象,则参数的结果决定了resolve的结果
const p2 = Promise.resolve(new Promise((resolve, reject) => {
    // resolve("成功")   // 由这里的结果决定返回的实例对象的结果,返回一个成功状态的Promise对象
    reject("失败")
}))
p2.then((value)=>{
    console.log(value);  // 成功
},(reason)=>{
    console.log(reason); // 失败
})
2.reject()​
Promise.reject()方法：(reason)=>{}
	(1) reason: 失败的原因
	说明: 返回一个失败的promise 对象,
3.all([])​
Promise.all()方法：(promises)=>{}
	(1) promise: 包含n个promise的数组
	说明: 返回一个新的promise 对象(包含多个Promise的执行结果),只有所有的promise都成功才成功,只要有一个失败就直接失败
	function sum(a,b) {
    	return new Promise((resolve,reject) => {
    		resolve(a+b)
    	})
    }
    let result = Promise.all([sum(1,2),sum(1,2),sum(1,2)])
    console.log(result);

	result.then(value=> {
	console.log(value);
})
4.allSettled([ ])​
Promise.allSettled([])方法：(promises)=>{}
	(1) promise: 包含n个promise的数组
	说明: 返回一个新的promise 对象(包含多个Promise的执行结果),不论成功或者失败
5.race()​
Promise.all()方法：(promises)=>{}
	(1) promise: 包含n个promise的数组
	说明: 返回一个新的promise 对象,第一个完成的promise的结果状态就是最终的结果状态

8.手写Promise​

// 声明构造函数
function Promise(executor) {
    // 添加属性
    this.PromiseState = 'pending';
    this.PromiseResult = null;

    // 声明属性
    this.callbacks = [];
    
    let _this = this;
    // resolve函数
    function resolve(data) {
        //判断状态,使对象状态只能修改一次
        if (_this.PromiseState !== 'pending') return;
        // 1.修改对象的状态(PromiseState)
        _this.PromiseState = 'fulfilled';
        // 2.设置对象结果值(promiseResult)
        _this.PromiseResult = data;
        // 调用成功的回调函数
        _this.callbacks.forEach(item => {
            item.onResolved(data)
        })
    }
    
    // reject函数
    function reject(data) {
        //判断状态
        if (_this.PromiseState !== 'pending') return;
        // 1.修改对象的状态(PromiseState)
        _this.PromiseState = 'rejected';
        // 2.设置对象结果值(promiseResult)
        _this.PromiseResult = data;
        // 调用成功的回调函数
        _this.callbacks.forEach(item => {
            item.onRejected(data)
        })
    }

    // throw抛出异常改变状态
    try {
        // 同步调用 [执行器函数]
        executor(resolve, reject);
    } catch (e) {
        // e是结果值
        // 修改promise对象状态为  [失败]
        reject(e)
    }
}

// 添加then方法
Promise.prototype.then = function (onResolved, onRejected) {
    const _this = this
    return new Promise((resolve, reject) => {
        // 调用回调函数 先判断PromiseState的状态
        if (this.PromiseState === "fulfilled") {
            try {
                // 获取回调函数的执行结果
                let result = onResolved(this.PromiseResult);
                // 判断
                if (result instanceof Promise) {
                    // 是Promise类型的对象
                    result.then(v => {
                        resolve(v)
                    }, r => {
                        reject(r)
                    })
                } else {
                    // 结果的对象状态为  [成功]
                    resolve(result)
                }
            } catch (e) {
                reject(e)
            }
        }
        if (this.PromiseState === "rejected") {
            onRejected(this.PromiseResult);
        }
        // promise中是异步任务时,判断pending状态
        if (this.PromiseState === "pending") {
            // 保存回调函数
            this.callbacks.push({
                onResolved: function () {
                    // 执行成功的回调函数
                    onResolved(_this.PromiseResult)
                },
                onRejected: function () {
                    // 执行失败的回调函数
                    onRejected(_this.PromiseResult)
                }
            })
        }
    })
}

9.async与await​

1.async​
// 1.async函数的返回值是Promise对象
// 2.Promise对象的结果由async函数执行的返回值决定
// 3.如果async声明的函数中没有写await,那么它里面的代码就会依次执行
// 4.使用await调用函数后,当前函数后面的所有代码会在当前函数执行完毕后,被放入到微任务队列中

async function main(){
    // 1.如果返回值是一个非Promise类型的数据,则结果值为成功状态的Promise对象
    // return 666
    // 2.如果返回值是一个Promise类型的数据,则结果值由传的参数决定值与状态
    // return new Promise((resolve,reject)=>{
    //     resolve("成功")
    //     reject("失败")
    // })
    // 3.抛出异常,则结果值为失败状态的Promise对象
    throw "哦,失败了"

}
let result = main()
console.log(result);

2.await​
// 1.await右侧的表达式一般为Promise对象,但也可以是其他的值
// 2.如果表达式是Promise对象,await返回的是Promise成功的值
// 3.如果表达式是其他值,直接将此值作为await的返回值
// 4.await必须写在async函数中,但async函数中可以没有await
// 5.如果await后的Promise失败了,就会抛出异常,需要通过try...catch捕获处理
// 6.await只会阻塞async声明的异步函数内部的依赖await结果的代码,不会影响其外部代码

async function main(){
    let p =  new Promise((resolve,reject)=>{
        // resolve("成功")
        reject("失败")
    })

    // 1. 右侧是Promise的情况
    // let result1 = await p
    // console.log(result1);
    // 2. 右侧是其他类型的数据
    let result2 = await 666
    console.log(result2);
    // 3. 右侧是失败的Promise情况
    try{
        let result3 = await p
    }catch(error){
        console.log(error);
    }
}
main()

10.Promise的面试题​

// 1.如何改变Promise的状态
	-1.resolve(value):如果当前是pending就会变成fulfilled
	-2.reject(reason):如果当前是pending就会变成rejected
	-3.抛出异常:如果当前是pending就会变成rejected

// 2.一个Promise指定多个成功/失败的回调函数,都会调用吗?
	-1.当Promise改变为对应状态时都会调用


// 3.改变Promise的状态和指定回调函数谁先谁后?
	-1.都有可能,正常情况下是先指定回调再改变状态,但也有可能先改变状态再指定回调
	-2.如何先改变状态再指定回调?
		1.在执行器中直接调用resolve()/reject()
		2.延迟更长时间调用then()
	-3.什么时候才能得到数据?
		1.如果先指定的回调,那当状态发生改变时,回调函数就会调用,得到数据
        let p = new Promise((resolve, reject) => {
            setTimeout(() => {
                console.log("状态发生改变");
                resolve("成功")
            }, 5000)
        })    
        p.then((value) => {
            console.log("5S后得到数据");
            console.log(value);
        })
		2.如果先改变状态,那当指定回调时,回调函数就会调用,得到数据
		let p = new Promise((resolve, reject) => {
        console.log("先改变状态");
        resolve("成功")
        })    
        p.then((value) => {
        console.log("得到数据");
        console.log(value);
        })

// 4.promise.then()返回的新Promise的结果状态由什么决定?
	-1.简单表达: 由then()指定的回调函数执行的结果决定
	-2.详细表达:
		1.如果抛出异常,新的Promise变为rejected,reason为抛出的异常
		2.如果返回的是非Promise的任意值,新Promise变为resolved,value为返回的值
		3.如果返回的是另一个新的Promise,此Promise的结果就会成为新Promise的结果
		let result = p.then(value => {
        // console.log(value);
        // 1.抛出异常
        // throw "出错了"
        // 2.返回非Promise类型的对象
        // return 521
        // 3.返回的是另一个新的Promise
        return new Promise((resolve, reject) => {
        // resolve("成功")
        reject("失败")
        })
        }).catch(reason =>{
        console.warn(reason);
        })
        console.log(result);
// 5.Promise如何串联多个操作任务?
	-1.promise的then()返回一个新的Promise,可以开成then()的链式调用
	-2.通过then的链式调用串联多个同步/异步任务

// 6.Promise穿透异常?
	-1.当使用Promise的then链式调用时,可以在最后指定失败的回调
	-2.当前任何操作出了异常,都会传到最后失败的回调中处理
	let p = new Promise((resolve, reject) => {
    	setTimeout(()=>{
    		resolve("成功")
    	},2000)
    })
    p.then(value => {
    	console.log(1);
    }).then(value => {
    	console.log(2);
    }).then(value => {
    	console.log(3);
    }).catch(reason=> {
    	console.warn(reason);  // 出错了就会到这里处理
    })

// 7.中断Promise链?
	-1.当使用Promise的then链式调用时,在中间中断,不再调用后面的回调函数
	-2.办法: 在回调函数中返回一个pending状态的Promise对象

let p = new Promise((resolve, reject) => {
    setTimeout(()=>{
        resolve("成功")
    },2000)
})

p.then(value => {
    console.log(1);
    return new Promise(()=>{})   // 只有这一个办法
}).then(value => {
    console.log(2);
}).then(value => {
    console.log(3);
}).catch(reason=> {
    console.warn(reason);
})
