2.本地仓库命令使用​

  1. 基础简介

    git有两种状态:
    	未跟踪: 没有被git管理的文件,比如新添加的文件,状态U
    	已跟踪:
    		未修改:没有修改的文件,无状态
    		已修改:修改已经添加到暂存区的文件,状态M
    		已暂存:git add.的文件,状态A
    git的状态改变:
    	未跟踪 --------git add . -------已暂存     			   >>>U---A
    	已暂存 --------修改工作区文件-------已修改			      >>>A---M
    	已暂存 ------git commit -m "提交信息" -------未修改		>>>A---无状态
    	git只能提交暂存区的文件,git commit -a -m "强制提交暂存区已修改的文件,未跟踪的文件不会提交"

    git的最终目的: 让文件处于未修改状态

  2. 基本命令

    git config --global user.name <username>	// 配置用户名
    git config --global user.email <useremail>	// 配置用户邮箱

    git -v				// 查看安装版本

    获取本地仓库的两种方式
    git init			// 初始化本地仓库
    git clone <url>		// 克隆远程仓库文件

    查看仓库文件状态
    git status		 	// 完整模式
    git status -s    	// 简洁模式

    添加文件到暂存区
    git add <filename>  // 把指定文件添加到暂存区
    git add .   		// 把全部文件添加到暂存区,只添加新建的和修改过的文件,不包括已删除的文件
    git add *   		// 把全部文件添加到暂存区,添加新增和已修改和删除文件的文件

    文件恢复和版本回滚
    git reset <filename> 		 // 把文件从暂存区恢复到工作区
    git reset --hard <commitid>  // 版本回滚,会覆盖工作区和暂存区,删除提交记录,用git reflog查看
    git switch <commitid> --detach	 // 版本回滚,分离头指针,操作前要先创建新分支

    恢复文件 
    git restore <filename>    		// 修改了文件但文件尚未加入暂存区,恢复到未修改状态
    git restore --staged <filename> // 把文件从暂存的状态取消
     
    删除文件
    git rm <filename> 		 	 // 将文件从仓库和工作区中删除,从仓库获取的文件有修改的话删除不了
    git rm <filename> -f	 	 // 强制删除

    添加文件到Git仓库
    git commit -m "提交信息"	  // 把暂存区文件提交到本地Git仓库
    git commit -a -m "提交信息"	  // 跳过暂存区把已修改文件提交到本地Git仓库

  3. 分支

    git branch					// 查看本地分支
    git branch -d <branchname>	// 删除分支

    git switch <branchname>			// 切换分支
    git switch -c <branchname>		// 创建并切换到该分支
    git checkout -b <branchname>	// 创建并切换到该分支

    git merge <branchname>			// 合并分支

    // 合并分支有两种结果:
    	快速合并: 主分支直接合并其他分支
    	合并冲突: 不同分支对同一文件有修改,需要手动解决冲突
    	
    // 合并分支有两种方式:
    	合并: 就像高速路与旁边小道
    	变基:	一条直线

    git rebase master   // 变基,先切换到要变基的分支,然后执行命令

  4. 变基

    原理:
    	1.当发生变基时,git会优先找到两条分支的最近的共同祖先
    	2.对比当前分支相对于祖先的历史提交,并将他们存储到一个临时文件中
    	3.将当前部分指向目标的基底
    	4.以当前基底开始,重新执行历史操作
    过程:
    	1.先切换到要变基的分支,git switch bug1
    	2.变基,git rebase master
    	3.解决冲突,提交
    	4.切回主分支,合并分支,git merge bug1
    	5.删除bug1分支
    	
    警告:
    	1.如果分支已经提交到远程仓库,尽量不要使用变基

3.远程仓库命令使用​

  1. 远程库网址

    gitee:  https://gitee.com/
    github: https://github.com/

  2. 常用命令

    git remote  						// 查看远程仓库
    git remote add <storename> <url>	// 连接远程仓库
    git remote remove <storename>		// 删除远程仓库

    git remote add origin https://github.com/xiyou-hao/test.git // origin是远程仓库别名
    git branch -M main			// 将本地主分支改名为main
    git push -u origin main  	// 推送到远程仓库origin的main分支上,-u是--set-upstream的缩写
    git push					// 必须本地仓库版本≥远程仓库版本才能推送成功,先拉再推

    git push 远程库 本地分支:远程分支// 完整写法,本地分支推远程分支

    git clone <url> 		// 克隆仓库
    git clone <url> <name>	// 克隆仓库并取别名
    git pull  				// 拉取远程仓库代码

  3. 标签

    git tag							// 列出所有标签
    git tag <tagname>				// 创建标签
    git tag -d <tagname> 			// 删除本地标签
    git tag <commitid> <tagname>	// 指定提交记录打标签
    git tag <storename> <tagname> 	// 推送远程标签
    git checkout -b <branchname> <tagname> 	// 回滚到标签位置
    git switch -c <branchname> <tagname>   	// 回滚到指定标签
    git push <storename> --delete <tagname> // 删除远程仓库标签

4.github部署静态页面​

  1. 要求静态页面的分支名称叫gh-pages
  2. 推送成功后看settings--->pages
  3. 通过 账号名.github.io/仓库名 访问网站
  4. 通过 账号名.github.io 访问网站需要设置仓库名为 账号名.github.io
